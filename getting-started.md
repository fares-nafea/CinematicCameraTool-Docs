# Getting started

> Install Cinematic Camera Tool and make your first cinematic.

Cinematic Camera Tool lets you build camera cinematics in Roblox Studio without writing code. Set a Start and an End camera for each shot, preview the move, add transitions, and export a video.

## What you can do

- Make **shots** with a Start and End camera, a duration and an easing
- Arrange shots on a **timeline** (drag to reorder, drag the edge to resize)
- Add **CUT, FADE and CROSSFADE** transitions
- Use live camera tools: **Look At, Follow, Shake, Advanced Shake, Rig, Path**
- Save **scenes** and camera **presets**
- **Record** a Preview and export the camera data (.rbxm)
- **Export MP4**: a real video file (needs a free helper program)

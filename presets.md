# Presets

> Save a camera position under a name and return to it any time.

A preset stores the current viewport camera (position, rotation and field of view) under a name.

## Save a preset

1. Move the viewport camera where you want it.
2. In **PRESETS**, type a name (up to 40 characters).
3. Press **Save Preset**.

If the name already exists, press **Save Preset** a second time to replace it.

## Use a preset

- **Apply:** moves the camera back to that preset.
- **Delete:** removes it. It asks for a second click to confirm.

## Good to know

- Presets are kept in Studio's plugin settings, separate from scenes.
- Presets are ignored while a Preview runs.
- Presets are for places you want to return to. For a move, use shots.

## Common mistakes

- **Nothing happens:** stop the Preview first.
- **A name is refused:** names can be at most 40 characters.

# Advanced Shake

> Layered shakes with position, rotation, fades and presets.

**ADVANCED SHAKE** is a more detailed shake. You control the position and rotation strength, a fade in, a hold and a fade out, and you can run several layers at once.

## Steps

1. Set **Intensity**, **Frequency** and **Duration**.
2. Set the **Position** strength (X, Y, Z) and the **Rotation** strength (Pitch, Yaw, Roll).
3. Set the **Fade (In / Hold / Out)** times.
4. Press **Start Shake**. Press it again to stop.

## Layers

Several layers can run together, up to 16. Start the shake again to add another layer. The editable boxes control the first (primary) layer.

## Shake presets

Presets save a whole shake setup.

- **Built-in presets:** Light Impact, Medium Impact, Heavy Impact, Explosion, Earthquake, Horror and Landing.
- **Your own presets:** type a name (up to 40 characters) and press **Save Preset**. You can save up to 40.
- **Apply** loads a preset into the boxes. **Delete** removes your own preset and asks for a second click.

## Good to know

- Advanced Shake is a **live tool**: one at a time, a Preview stops it, and the camera returns when it ends.
- It is not baked into shots, recordings or the MP4.
- Simple [Shake](shake.md) and Advanced Shake do not run at the same time.

## Common mistakes

- **No visible shake:** check that the position or rotation strength is not zero.
- **A preset name is refused:** names can be at most 40 characters.

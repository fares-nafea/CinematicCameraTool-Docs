# Rig

> Track a target in Follow, Orbit or Look At mode.

**RIG** tracks a target with the camera while it runs. It has three modes.

## Modes

- **Follow:** the camera follows the target from a distance.
- **Orbit:** the camera circles around the target.
- **Look At:** the camera stays where it is and keeps facing the target.

## Steps

1. Select a **part, model or attachment** and press **Pick Target**.
2. Choose a **mode**.
3. Set the settings below.
4. Press **Start Rig**. Press it again to stop.

## Settings

- **Distance:** 12 by default (0.1 to 100).
- **Height:** 5 by default (-50 to 50).
- **Side:** 0 by default (-50 to 50).
- **Angle:** 0 by default (-180 to 180 degrees).
- **Smoothness:** 0.15 by default. A lower number is smoother.

You can change the settings while the rig is running.

## Good to know

- Rig is a **live tool**: one at a time, a Preview stops it, and the camera returns when it stops.
- It is not part of the timeline, a recording or the MP4.
- If the target is deleted, the rig stops by itself.

## Common mistakes

- **Nothing happens:** pick a target first.
- **"Too close":** increase the distance.
- **Orbit looks static:** set the angle to something other than 0 and keep the rig running.

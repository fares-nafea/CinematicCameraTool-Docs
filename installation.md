# Installation

> Install the plugin and open its panel in Roblox Studio.

## Install the plugin

1. Open the plugin's page on the Roblox Creator Store: [Cinematic Camera Tool](https://create.roblox.com/store/asset/77223219873043/Cinematic-Camera-Tool)
2. Install it, then **restart Roblox Studio**.
3. Open a place (a new Baseplate is fine).

## Open the panel

1. In Studio, open the **Plugins** tab.
2. Find **Cinematic Camera Tool** and click **Camera Tool**.
3. The panel opens as a floating window. You can dock it next to the viewport.

Click **Camera Tool** again to hide the panel.

## If the plugin does not appear

- Restart Roblox Studio after installing.
- Check the **Plugins** tab (not only the Home tab).
- Make sure the plugin is not turned off in the plugin manager.

## For Export MP4 only

MP4 export needs extra software on your computer. See [MP4 export](mp4-export.md).

- **Python 3**
- **FFmpeg**
- **The encoder helper**, a small program you download once

Everything else in the plugin works without them.
